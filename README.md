# AI Guesses, People Check

A one-page explainer on artificial intelligence for a general audience: what it is, where it helps, four real case files where it went wrong, its electricity demand, and possible futures. Every claim is labelled **Fact**, **My take** or **Prediction**.

Live site: https://USERNAME.github.io/ai-project/

## Files

```
ai-project/
├── index.html      page content (semantic HTML)
├── styles.css      layout, colour variables, dark mode, mobile-first
├── script.js       next-word demo, accessible case-file tabs, menu highlight
└── assets/         SVG diagram and chart (desktop + mobile versions), favicon
```

No build step, no libraries. Open `index.html` in a browser to test locally.
